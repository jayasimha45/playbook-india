# PlayBook India — booking experience demo

A responsive, static preview of a sports venue discovery and booking experience. All venue details, ratings, reviews, prices, cancellation examples, and slot availability are sample content. The page does not create bookings, accept payments, save venue submissions, or authenticate users.

## Run locally

Open `index.html` in a modern browser. No build step is required.

## Files

- `index.html` — page structure, demo notice, metadata, and accessible dialogs
- `style.css` — responsive styling
- `script.js` — sample venue search, filters, venue cards, and preview dialogs
- `assets/venue-*.png` — sample venue imagery
- `assets/reference-*.png` — supplied reference screenshots

## Before accepting real bookings

Replace the sample listings with venue-approved data and images; verify prices, reviews, amenities, and policies; connect server-backed availability with conflict-safe reservations; implement authentication, payment, booking confirmations, cancellations/refunds, customer support, and owner tools; publish accurate privacy and terms pages; and complete device, accessibility, security, and operational checks. The current project is a frontend demo and is not ready to process real bookings.
